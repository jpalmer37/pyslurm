# Changelog

All notable changes to this project are documented here. Releases follow [Semantic Versioning](https://semver.org/).

## 0.2.0

- Require submitit >= 1.5.4 and drop the setuptools 80 pin, so installs work with current setuptools.
- Add a supported CI matrix for Python 3.8–3.12.
- Document the execution architecture, outputs, audience, and operational limitations.

## 0.1.1

- Add bounded waits, array chunking, optional result collection, safer cleanup, and structured failure reporting.
